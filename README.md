# Customer Segmentation and Churn Pattern Analytics in European Banking

## Project Overview
This project focuses on analyzing customer data from the European banking sector to identify customer segments and understand customer churn patterns.

The application uses Python and Streamlit to provide an interactive dashboard for exploring customer behavior, performing customer segmentation, and analyzing churn trends.

## Objectives
- Analyze European banking customer data.
- Identify different customer segments.
- Understand customer churn patterns.
- Visualize important customer-related insights.
- Build an interactive dashboard using Streamlit.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Installation and Setup

**Step 1: Clone the repository**

```bash
git clone https://github.com/cspavithra57-coder/customer-segmentation-churn-analytics.git
```

**Step 2: Open the project folder**

```bash
cd customer-segmentation-churn-analytics
```

**Step 3: Install the required libraries**

```bash
pip install -r requirements.txt
```

**Step 4: Run the Streamlit application**

```bash
streamlit run app.py
```

## Dataset
The project uses the `European_Bank.csv` dataset containing customer information for banking analytics.

## Key Features
- Customer data analysis
- Customer segmentation

## How to Run
After installing the required libraries, execute `streamlit run app.py` in the terminal. The application will open in your browser.
